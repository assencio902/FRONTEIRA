┌────────────────────────────────────────────────────────────────────────┐
│ 🚀 COMO TESTAR NO APP                                                   │
├────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  1. Certifique-se que o backend está rodando:                          │
│     docker-compose up -d                                               │
│                                                                         │
│  2. Execute o app Flutter:                                             │
│     cd flutter_app                                                     │
│     flutter run -d chrome   (ou windows, android, etc)                │
│                                                                         │
│  3. Navegue para a tela "Mapas & Rotas"                                │
│                                                                         │
│  4. Observe:                                                            │
│     • Câmeras carregam automaticamente ao abrir a tela                 │
│     • Switch mostra quantas câmeras foram carregadas                   │
│     • Marcadores azuis/roxos aparecem no mapa                          │
│                                                                         │
│  5. Interaja:                                                           │
│     • Clique em um marcador → veja detalhes da câmera                  │
│     • Use o switch para mostrar/ocultar câmeras                        │
│     • Busque uma trajetória → veja câmeras + pontos no mesmo mapa     │
