┌─────────────────────────────────────────────────────────────────┐
│ 🔑 PASSO 1: OBTER SUA API KEY                                   │
└─────────────────────────────────────────────────────────────────┘

  1. Acesse: https://console.cloud.google.com/
  2. Crie um projeto novo
  3. Ative a API: "Maps JavaScript API"
  4. Vá em: APIs e serviços > Credenciais
  5. Clique: + CRIAR CREDENCIAIS > Chave de API
  6. COPIE a chave gerada (ex: AIzaSyBxxx...)

┌─────────────────────────────────────────────────────────────────┐
│ 🛠️ PASSO 2: CONFIGURAR NO SISTEMA                               │
└─────────────────────────────────────────────────────────────────┘

  📁 ARQUIVO: d:\monitoramento\ingest\static\dashboard.html
  
  📍 LOCALIZAÇÃO: Linha 12 (dentro da tag <head>)
  
  🔍 PROCURE POR:
  
    key=YOUR_API_KEY
  
  ✏️ SUBSTITUA POR:
  
    key=SUA_CHAVE_AQUI
  
  📝 EXEMPLO COMPLETO:
  
    <script src="https://maps.googleapis.com/maps/api/js
    ?key=AIzaSyBxxxYYYzzz1234567890abcdefGHIJKL
    &callback=Function.prototype" async defer></script>

┌─────────────────────────────────────────────────────────────────┐
│ 🐛 PROBLEMAS COMUNS                                             │
└─────────────────────────────────────────────────────────────────┘

  ❌ Mapa não carrega (tela cinza):
     → Verifique se API Key está correta
     → Certifique que Maps JavaScript API está ativa
     → Abra Console do navegador (F12) para ver erros
  
  ❌ Marcadores não aparecem:
     → Verifique se câmeras têm coordenadas GPS cadastradas
  
  ❌ Erro "RefererNotAllowedMapError":
     → Adicione seu domínio nas restrições da API Key
